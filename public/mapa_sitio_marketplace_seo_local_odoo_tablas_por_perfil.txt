MAPA DEL SITIO DEL MARKETPLACE SEO LOCAL + ODOO REFERENCIAL
Perfiles de usuario públicos y privados + módulos funcionales Odoo nativos referenciales + módulos propios SEO Local + tablas por perfil

CRITERIO DE ARQUITECTURA
No existe integración técnica entre el ERP Odoo y el Marketplace de SEO Local.
Odoo se usa únicamente como referencia de normalización funcional y de base de datos.
Las tablas propias del Marketplace SEO Local se crean cuando la lógica de negocio no queda soportada por tablas nativas de Odoo.
Las tablas propias usan prefijo seo_* para separarlas de las tablas nativas Odoo.
Las tablas Odoo se listan como referencia conceptual, no como dependencia técnica obligatoria ni como integración directa.

REGLA DE DECISIÓN
├── Usar tabla Odoo nativa como referencia cuando la lógica sea estándar:
│   ├── Usuarios, contactos, compañías, grupos, permisos
│   ├── CRM, leads, oportunidades
│   ├── Catálogo de productos/servicios, listas de precio
│   ├── Cotizaciones, órdenes, facturas, pagos
│   ├── Proyectos, tareas, actividades
│   ├── Helpdesk, mensajes, adjuntos
│   ├── Website, páginas, menús, formularios
│   └── Rating, documentos, calendario, reportes básicos
└── Crear tabla propia SEO Local cuando la lógica sea específica:
    ├── Directorio de agencias SEO Local
    ├── Perfil público ampliado de agencia
    ├── Especialidades conectadas a 45 servicios SEO
    ├── Ranking interno de agencias
    ├── Comparador de servicios/agencias
    ├── Marketplace de contratación de servicios SEO
    ├── Gestión de reseñas y reputación GBP
    ├── Auditoría SEO Local
    ├── Google Business Profile / GBP
    ├── Local Pack, mapas, grid geográfico y keywords locales
    ├── NAP, citaciones y directorios
    ├── Link building local y PR local
    ├── Schema local, páginas locales y contenido local
    ├── Reportes SEO, KPIs, dashboards y snapshots
    └── Evidencias, entregables, aprobaciones y flujos FUR

NOTAS DE NORMALIZACIÓN
├── Las tablas Odoo no se copian ni se integran; sirven como guía de nombres, dominios funcionales y normalización.
├── El Marketplace SEO Local debe tener su propio esquema transaccional.
├── Las tablas seo_* deben relacionarse entre sí por claves propias del marketplace.
├── Las referencias a Odoo deben quedar documentadas solo como equivalencia conceptual.
├── Las tablas de herramientas externas SEO deben guardar snapshots y referencias, no depender de una integración con Odoo.
├── Las tablas de reseñas, GBP, Local Pack, NAP, citaciones, backlinks, schema y auditorías son propias porque Odoo no modela esa lógica SEO Local.
├── Las tablas de venta, proyecto, CRM y helpdesk pueden inspirarse en Odoo, pero el marketplace debe mantener sus propias tablas cuando existan reglas de marketplace, comisiones, comparador, ranking, entregables SEO o aprobaciones.
└── La versión final de base de datos debe validarse contra los FUR definitivos y contra las pantallas públicas/privadas aprobadas.
